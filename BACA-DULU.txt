UHUYY PLAYER - cara dapetin APK (tanpa Android Studio)

=== A. REPO BARU (paling aman, mulai bersih) ===
1. Buka github.com, login, buat repo baru (Private boleh). Centang "Add a README" biar repo-nya langsung ada isinya.
2. Ekstrak ZIP ini di HP/PC.
3. Bikin file workflow DULU lewat tulisan (jangan lewat upload, karena folder .github yang tersembunyi sering nggak ikut):
   Add file > Create new file. Di kolom nama ketik persis:
       .github/workflows/build.yml
   (ketik garis miring "/" biar jadi folder). Buka build.yml dari ZIP, copy semua isinya, paste, lalu Commit.
4. Upload sisanya: Add file > Upload files. Pilih semua file dan folder KECUALI folder ".github":
   app/ , build.gradle.kts , settings.gradle.kts , gradle.properties , .gitignore
   Kalau di HP nggak bisa upload folder sekaligus: pakai mode "Desktop site" di browser, atau upload per folder.
   PENTING: file app/uhuyy.jks (kunci tanda tangan) harus ikut keupload.
5. Tab Actions > tunggu "Build APK" selesai (centang hijau, sekitar 5-10 menit).
6. Klik run-nya, scroll ke Artifacts, download "UhuyyPlayer-release-apk", ekstrak, install app-release.apk.

=== B. REPO LAMA (yang sudah ada) - update file ===
Cara paling gampang: ganti/tambah file ini satu-satu (di GitHub: buka file > ikon pensil untuk ganti isi,
atau Add file > Upload files untuk file baru).

GANTI ISI:

  build.gradle.kts            (yang di paling luar)
  app/build.gradle.kts

  app/src/main/java/com/uhuyy/player/PlayerActivity.kt

TAMBAH BARU:

  app/src/main/java/com/uhuyy/player/Settings.kt  (Ronde 3)

HAPUS (WAJIB, kalau nggak build/ikon bermasalah di Android lama):
  app/src/main/res/mipmap-anydpi/ic_launcher.xml
  (buka file itu di GitHub > ikon tong sampah / titik tiga > Delete file > Commit)

=== PENTING SEBELUM INSTALL ===
APK baru ini ditandatangani kunci tetap, beda sama APK debug lama. Jadi UNINSTALL dulu aplikasi
Uhuyy Player yang lama (foto latar dan posisi terakhir nonton ikut hilang, itu sekali ini aja).
Build-build berikutnya bisa langsung di-install menimpa tanpa uninstall.

=== KALAU BUILD GAGAL ===
- Kalau cuma ada artifact "UhuyyPlayer-DEBUG-cadangan-apk": release gagal tapi debug jalan. APK itu lebih berat.
  Buka run-nya, klik langkah "Build release APK", screenshot/copy log merahnya, kirim ke Claude.
- Kalau silang merah semua: buka run-nya, klik langkah yang merah, kirim log-nya.
- Workflow juga otomatis gagal kalau ada izin INTERNET nyelip (app ini harus offline) atau APK > 100 MB.

Ganti nama aplikasi: app/src/main/res/values/strings.xml (isi app_name).
